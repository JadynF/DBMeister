# DBMeister Installation and Usage Documentation

---

# Installation

---

<blockquote>
1. Clone the GitHub repo located at https://github.com/JadynF/DBMeister
2. Run `npm i`
3. Install any further dependencies that you may be missing, all libraries are located in package.json
</blockquote>

# Usage

---

<blockquote>

## Running in Developer Mode

<blockquote>

1. Run `npm run dev`
2. The Next.JS app will start in developer mode, any changes you make to app files will automatically show
3. Access at localhost:3000

</blockquote>

## Running Statically

<blockquote>

1. In the root directory, run `npm run build`
2. Wait for the build to complete
3. Run `npm run start`
4. The app will start, access at localhost:3000

</blockquote>

</blockquote>
